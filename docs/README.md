## 🚀 Quick Start

### Para Iniciantes
1. Leia [DOCUMENTACAO.md](DOCUMENTACAO.md) inteira
2. Pratique com as tarefas em [GUIA_RAPIDO.md](GUIA_RAPIDO.md)
3. Teste localmente antes de fazer push

### Para Desenvolvedores Experientes
1. Leia [DOCUMENTACAO_TECNICA.md](DOCUMENTACAO_TECNICA.md)
2. Clonar repositório: `git clone <repo-url>`
3. Fazer alterações
4. Commit e push

### Para Manutenção Rápida
1. Abra [GUIA_RAPIDO.md](GUIA_RAPIDO.md)
2. Procure a tarefa que precisa
3. Siga o copy-paste fornecido
4. Commit e push

## ✅ Checklist de Verificação

Antes de fazer push para produção:

- [ ] Abri `index.html` localmente no navegador
- [ ] Todos os CSS carregaram (cores aparecem)
- [ ] Todas as imagens aparecem
- [ ] Todos os links funcionam
- [ ] Não há erros no console (F12)
- [ ] Revisei erros de digitação
- [ ] Realizei commit com mensagem clara
